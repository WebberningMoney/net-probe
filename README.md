> 幫你看懂「家裡網路到底穩不穩、卡的時候問題出在哪一段」的 Mac 小工具。

## 1. 這是什麼？能幫我什麼？

你有沒有遇過：

- 視訊會議突然卡住、聲音斷斷續續，但 Wi-Fi 圖示明明是滿格？
- 打電動「Lag」，不知道是自己家的問題，還是遊戲伺服器的問題？
- 打給網路公司客服，對方說「我們這邊測起來都正常」？

**NetSonar 幫你「用數據說話」。**

它的做法很像「對著山谷大喊，聽回音要多久」：每秒對幾個網路上很穩定的地方（例如中華電信、Google 的伺服器）各「喊」一聲，記下回音多快回來、有沒有回來。

| 比喻 | 正式名稱 | 意思 |
|---|---|---|
| 喊一聲，回音多久回來 | **延遲** | 越小越好 |
| 回音有時快、有時慢 | **抖動** | 越小越穩 |
| 喊了卻沒聽到回音 | **丟包** | 越接近 0% 越好 |

它還會**同時量你家的路由器**（家裡那台網路分享器）。這是找原因的關鍵：

- **連路由器都忽快忽慢** → 問題在你家裡（Wi-Fi、路由器、這台電腦）。
- **路由器很穩，只有外面的網站慢** → 問題在你家之外（網路公司或遠端伺服器）。

所有資料只存在你自己的電腦裡，不需要帳號，不會上傳。

| 你的情況 | 適合嗎 |
|---|---|
| 想知道家裡網路到底穩不穩 | ✅ |
| 想知道卡頓是自己家的問題還是網路公司的問題 | ✅ |
| 想比較不同設定（換頻道、關藍牙、換位置）哪個比較好 | ✅ 有「測試報告並排比較」 |
| 想留下證據給網路公司 | ✅ 可下載 CSV、列印報告 |
| 想測「網速最高幾 Mbps」 | ⚠️ 有簡易下載測速，但不是完整測速 |
| 使用 Windows 或 Linux | ❌ 目前只支援 Mac |

## 2. 安裝（第一次，約 5 分鐘）

### ① 先確認電腦有 Python（只需要做一次）

Python 是這個工具用的程式語言，需要 3.10 以上的版本。Mac 內建的版本通常太舊。

1. 按 `⌘ + 空白鍵`，輸入 `終端機`（或 `Terminal`），按 Enter。
2. 在跳出的視窗輸入下面這行，按 Enter：
   ```bash
   python3 --version
   ```
3. 看結果：
   - 顯示 `Python 3.10` 或更大的數字（例如 `3.13.5`）→ 可以了，跳到步驟 ②。
   - 顯示 `3.9` 或更小、或出現錯誤 → 到 [python.org 下載頁](https://www.python.org/downloads/macos/) 下載最新版的 macOS 安裝檔，像一般軟體一樣安裝即可。

> 💡 終端機就是「用打字下指令」的視窗。安裝完成後，日常使用**不需要**再打開它。

### ② 下載 NetSonar

**方法 A（最簡單）：下載 ZIP**
到 [GitHub 專案頁](https://github.com/WebberningMoney/net-sonar)，按綠色的 **Code → Download ZIP**，下載後雙擊解壓縮，把資料夾放在你找得到的地方（例如桌面）。

**方法 B（之後更新比較方便）：用 git 下載**
在終端機輸入：
```bash
cd ~/Desktop
git clone https://github.com/WebberningMoney/net-sonar.git
```
桌面就會多一個 `net-sonar` 資料夾。

### ③ 雙擊安裝

打開 `net-sonar` 資料夾，**雙擊 `安裝.command`**。

會跳出一個視窗自動跑安裝（第一次約 1～2 分鐘），完成後會自動打開瀏覽器，顯示儀表板。

裝好之後，「**應用程式**」資料夾（和 Launchpad）裡會多一個 **NetSonar** 圖示。以後點它就能打開儀表板，也可以把它拖到 Dock。
想用書籤也可以，網址是：

```
http://127.0.0.1:8765
```

> ⚠️ **如果 Mac 說「無法打開」或「無法確認開發者」**：
> 這是因為這個檔案不是從 App Store 來的，macOS 會先擋下來。請：
> 1. 在 `安裝.command` 上**按右鍵 → 打開**，再按「打開」。
> 2. 如果還是不行：打開「系統設定 → 隱私權與安全性」，往下捲，會看到被擋下的檔案，按「**仍要打開**」。

### 安裝做了什麼？

- 把程式複製到 `~/Library/Application Support/NetSonar`（macOS 允許背景程式讀取的位置），並準備好它需要的元件。
- 設定成**開機登入後自動在背景執行**，萬一程式意外停止也會自動重新啟動。之後不用開終端機，也不會出現視窗。
- 在「應用程式」放一個 NetSonar 圖示。它是一個小小的「啟動器」：點它會先確定背景程式有在跑，再幫你打開儀表板。
  （程式本體不在這個圖示裡，所以不用、也不要自己把 `net-sonar` 資料夾搬進「應用程式」。）
- 之前用終端機啟動時在「設定」頁改過的內容，會一起帶過去。

## 3. 每天怎麼用

**點「應用程式」裡的 NetSonar 圖示（或瀏覽器書籤 `http://127.0.0.1:8765`）就好。**

- 它一直在背景量，你什麼時候打開都能看到最近的狀況。
- 網路變差時，右上角會跳出 macOS 通知（同一類問題 5 分鐘內只通知一次，不會一直吵）。
- **關掉瀏覽器不會停止量測**，背景程式會繼續記錄。重開機後也會自動繼續。

### 想讓它停下來？

| 你想要 | 怎麼做 |
|---|---|
| 只是不看了 | 直接關掉瀏覽器分頁。背景繼續量，這是正常的 |
| 暫時完全停止（不量測、不通知） | 儀表板「設定」頁最下方 →「⏻ 停止 NetSonar」。之後點 NetSonar 圖示，或下次登入電腦，就會再啟動 |
| 永久移除 | 雙擊 `解除安裝.command`（見[移除](#9-移除)） |

### 資料存在哪裡？

| 內容 | 位置 |
|---|---|
| 量測資料（資料庫） | `~/Library/Application Support/NetSonar/data/netprobe.db` |
| 你在「設定」頁改的設定 | `~/Library/Application Support/NetSonar/data/settings.json` |
| 程式本體 | `~/Library/Application Support/NetSonar/app/` |
| 執行紀錄（出問題時查看） | `~/Library/Logs/NetSonar.log` |

`~` 代表你的家目錄。想在 Finder 打開：選單「前往 → 前往檔案夾」，貼上路徑。「設定」頁最下方的「關於這個程式」也會顯示實際位置。

> 💡 `127.0.0.1` 是「這台電腦自己」的意思。這個網頁只有你自己的電腦打得開，同一個 Wi-Fi 的其他人看不到。

## 4. 畫面導覽

上方有五個分頁：

| 分頁 | 用途 |
|---|---|
| **即時** | 最常看的頁面：整體網路建議、各目標的即時數字、延遲走勢圖、網路環境、最近的警示 |
| **歷史** | 看過去 5 分鐘～7 天的變化，可下載 CSV |
| **定時測試** | 量一段固定時間（5／15／60 分鐘或自訂），結束後產生報告並自動保存，可以把不同條件的報告並排比較；也有下載測速 |
| **路徑分析** | 一站一站看「從你家到某個網站」經過哪些地方、哪一站開始變慢 |
| **設定** | 在網頁上直接修改：要量哪些目標、多久量一次、警示門檻等，存檔後馬上生效 |

### 下載 CSV 與清除紀錄

每個「有紀錄」的區塊，標題右邊都有兩顆按鈕：

| 按鈕 | 作用 |
|---|---|
| **⬇ 下載 CSV** | 把那個區塊的紀錄存成表格檔，可以用 Excel、Numbers 或 Google 試算表打開（中文不會變亂碼） |
| **🗑 清除** | 刪掉那個區塊的紀錄。會先問你是否確定，**清除後無法復原**，想留底請先下載 CSV |

| 哪裡 | 下載 CSV 的內容 | 清除紀錄會刪掉 |
|---|---|---|
| 即時頁「延遲走勢」、歷史頁 | 每秒一筆的量測結果（最多 24 小時；歷史頁可只下載單一目標） | 所有量測資料：走勢圖、歷史、各目標的統計都會歸零，然後從現在重新累積 |
| 即時頁「最近警示與事件」 | 警示與網路環境變化 | 警示與事件列表 |
| 定時測試頁「已保存的測試報告」 | 每份報告一列的比較表 | 所有測試報告（也可以在表格裡單獨刪一份） |
| 定時測試頁「下載速度測試」 | 每次測速的結果 | 測速結果列表 |
| 路徑分析頁 | 這次分析的每一站 | 畫面上的分析結果 |

「設定」頁最下方還有一顆「**清除所有紀錄**」，一次清掉上面全部。

- 什麼時候用：換到不同的環境測試之前（換了路由器、搬到別的地方、換網路公司），先清除，新舊資料才不會混在一起互相干擾。
- 你的設定（監測目標、警示門檻）**不會**被清除。
- 定時測試進行中，不能清除量測資料和測試報告（先結束測試）。

**小技巧**

- 看到不懂的名詞，旁邊的 **ⓘ** 滑過去（或點一下）就會出現白話說明。
- 滑鼠移到走勢圖上，會顯示那個時間點每個目標的實際數字。
- 圖下方的勾選框可以隱藏或顯示某條線。

## 5. 怎麼看懂結果

### 先看最上面的「整體網路建議」

它把所有檢查結果整理成幾個段落，每段前面有一個燈號：

| 燈號 | 意思 |
|---|---|
| 🟢 | 正常 |
| 🟡 | 值得留意，但還能用 |
| 🔴 | 建議處理 |
| ℹ️ | 參考資訊 |

段落包括：問題出在哪一段、Wi-Fi 連線、家裡這一段（到路由器）、連到外面的網路、抖動、DNS、VPN（有開才顯示）。每段都會附上「可以怎麼做」。

**不想看細節的話，看這一塊就夠了。**

### 每個目標的小卡片

| 欄位 | 白話 | 怎樣算好？ |
|---|---|---|
| 大數字 | 最新一次的延遲 | 台灣境內 30 ms 以下很好 |
| 平均 | 最近 5 分鐘的平均延遲 | 同上 |
| 慢的時候 | 最近 5 分鐘裡「比較慢的時候」有多慢（100 次裡有 95 次比它快） | 跟平均差不多＝很穩；比平均大很多＝常常突然卡一下 |
| 抖動 | 忽快忽慢的程度 | 5 以下很穩，超過 30 會明顯卡頓 |
| 丟包 | 沒有收到回應的比例 | 0% 最好，持續超過 1% 會感覺卡 |
| MOS | 拿這條網路打視訊或語音通話，順不順（1～4.5 分） | 4.3 以上極佳、4.0 以上良好 |
| 分數 | 延遲、抖動、丟包的綜合分數（0～100） | 見下表 |

卡片上方的色條代表分數等級：

| 顏色 | 等級 | 分數 | 感受 |
|---|---|---|---|
| 綠 | Excellent／Good | 75 以上 | 順暢 |
| 黃 | Moderate | 60～74 | 偶爾會卡 |
| 紅 | Poor | 60 以下 | 明顯有問題，**或是目標本來就很遠**（見下方說明） |

> 💡 **距離遠的目標分數本來就低**：例如 AdGuard、Quad9 的伺服器不在台灣，延遲 60～70 ms 是物理距離造成的，不是網路壞掉。只要它的抖動和丟包都很低，卡片會標示「距離較遠，偏慢屬正常」。如果它一直觸發警示，可以到「設定」頁替它調高門檻或勾選「靜音」。

### 延遲走勢圖

- 每條線是一個目標，越低越好。
- **好的網路**：線條平平的，偶爾有小起伏。
- **有問題的網路**：線條像鋸齒一樣一直跳。如果**所有線（包括路由器）在同一個時間一起跳**，問題就在你家裡。
- 灰色虛線：網路環境改變的時間點（例如切換 VPN、換 Wi-Fi 頻道）。
- 淡藍點線：程式讀取 Wi-Fi 詳細資訊的時間（macOS 讀取時會掃描周圍網路，可能造成短暫跳動）。
- 紅點：那個時間有丟包。

### 網路環境

顯示你目前怎麼連網：Wi-Fi 還是有線、路由器位址、DNS 是誰提供的、Wi-Fi 訊號強不強等。比較少用到的資訊（MTU、Proxy、IPv6、網路名稱）收在「進階資訊」裡。Wi-Fi 名稱和對外 IP 預設會遮住，按「顯示」才看得到。

## 6. 名詞小辭典

畫面上每個名詞旁都有 ⓘ 可以看說明，這裡集中整理一份：

| 名詞 | 白話解釋 |
|---|---|
| **延遲**（ms，毫秒） | 資料送出去再回來花的時間。1 秒 = 1000 ms。一般上網 50 ms 內很順，視訊或遊戲 100 ms 內都還可以 |
| **抖動** | 延遲忽快忽慢的程度。視訊、語音、遊戲最怕它 |
| **丟包** | 送出去卻沒有回應的比例 |
| **慢的時候**（p95） | 把所有測量由快排到慢，100 次裡有 95 次比這個數字快。平均值會把偶爾的卡頓藏起來，這個數字更接近你「感覺到卡」的時候 |
| **尖峰** | 延遲突然變很高的瞬間 |
| **逾時** | 等了一陣子都沒有回應 |
| **MOS** | 通話品質分（1～4.5），電信業用來評「通話聽起來順不順」的方式。本工具用延遲、抖動、丟包換算出近似值 |
| **分數** | 本工具自己的綜合分數（0～100），適合拿來比較，不是業界標準 |
| **路由器**（閘道） | 家裡的網路分享器，你的裝置連上網路的第一站 |
| **ISP** | 網路公司，例如中華電信、台灣大寬頻 |
| **DNS** | 把網址（google.com）翻成數字位址的服務，像網路的電話簿。它慢或壞了，網頁會一直轉圈圈 |
| **VPN** | 把網路流量先繞到另一台伺服器再出去的加密通道。開著時延遲會變高，這是正常的 |
| **IP** | 網路上的門牌號碼。「本機 IP」是家裡網路中的門牌；「對外 IP」是網站看到的你的門牌 |
| **頻段**（2.4／5 GHz） | Wi-Fi 的兩種「道路」。2.4 GHz 穿牆好但很擠；5 GHz 比較快、干擾少，但穿牆較弱 |
| **頻道** | 道路上的「車道」。鄰居用同一個車道，就會互相干擾 |
| **頻寬**（20／40／80 MHz） | 車道的寬度。越寬越快，但在鄰居很多的地方也越容易被干擾 |
| **訊號強度**（dBm） | Wi-Fi 收到的訊號有多強，數字越接近 0 越強。-50 以上極佳、-60 良好、-67 尚可、-70 以下偏弱 |
| **雜訊**（dBm） | 環境中的背景干擾。數字越小（越負）越好，-90 以下算很乾淨 |
| **訊噪比**（SNR） | 訊號比雜訊強多少，越大越好。40 以上極佳、25～40 良好、15～25 偏低 |
| **傳輸速率** | 電腦跟路由器之間「理論上」的速度。實際上網速度通常只有它的一半或更低 |
| **MTU** | 一次能傳送的最大資料包大小，一般是 1500，通常不用管 |
| **Proxy** | 上網前要先經過的中繼站，一般家用都是「無」 |
| **IPv6** | 新版的網路門牌格式，可不可用對一般使用沒有影響 |
| **Traceroute**（路徑分析） | 列出資料從你家到某個網站，一路經過的每一站 |

## 7. 實戰：找出網路卡卡的原因

這個工具最有用的地方，是能**一次只改一個條件**，比較前後差別。

### 步驟

1. 到「**定時測試**」頁，在「標籤」欄寫下目前的狀態（例如「原本的設定」），選 5 分鐘，按「開始測試」。
   測試期間照常使用電腦即可，不要刻意下載大檔案。
2. 測完後**只改一個東西**，例如：
   - 關掉藍牙
   - 把筆電移到離路由器近一點的位置
   - 在路由器設定把 Wi-Fi 頻寬從 80 MHz 改成 40 MHz
   - 換一個 Wi-Fi 頻道
3. 寫一個新標籤（例如「關藍牙」），再測 5 分鐘。
4. 在同一頁下方的「**已保存的測試報告**」表格，就能並排看每次的「家裡這一段」和「外面」的延遲、抖動、尖峰次數。數字明顯變小的那個條件，就是線索。

> 💡 一次只改一個條件很重要：同時改三樣東西，變好了也不知道是哪一個的功勞。
> 💡 要開始一輪全新的比較（例如換了路由器）？先到「設定」頁按「清除所有紀錄」，舊資料就不會混進來。想留底可以先下載 CSV。

### 作者自己的例子

作者家住在鄰居很多的社區，用 5 GHz Wi-Fi，延遲走勢圖一直呈現鋸齒狀，連到路由器的延遲都常常突然跳到 70 ms。

- 重開路由器、換位置、改 40 MHz：路由器的平均延遲有改善，但鋸齒還在。
- 關掉 AirDrop 和「接力」：沒有影響。
- **關掉藍牙**（當時沒有使用任何藍牙裝置）：線條立刻變平，到路由器的抖動從約 14 ms 降到 0.5 ms。

奇怪的是，藍牙用的是 2.4 GHz，照理不會干擾 5 GHz 的 Wi-Fi。一個可能的解釋是：很多 Mac 的 Wi-Fi 和藍牙在同一顆晶片上，藍牙在背景掃描時，晶片會短暫暫停 Wi-Fi。不過這只是推測，還沒有證實。**重點是：沒有實際量測，很難猜到是藍牙。**

## 8. 更新到新版

**用 ZIP 下載的**：重新下載 ZIP、解壓縮，再雙擊新資料夾裡的 `安裝.command`。你的設定和歷史資料會保留。

**用 git 下載的**：在終端機輸入：
```bash
cd ~/Desktop/net-sonar
git pull
```
然後雙擊 `安裝.command`。

> 只更新資料夾還不夠，一定要**再雙擊一次 `安裝.command`**，背景執行的程式才會換成新版。

## 9. 移除

雙擊資料夾裡的 `解除安裝.command`。它會問你要不要一起刪掉歷史資料和設定：

- 回答 `y`：全部刪除。
- 直接按 Enter：只移除程式，資料保留在 `~/Library/Application Support/NetSonar/data`（之後重新安裝會繼續使用）。

「應用程式」裡的 NetSonar 圖示也會一併移除。最後把 `net-sonar` 資料夾丟到垃圾桶即可。

## 10. 隱私：它會連到哪些地方？

所有量測結果只存在你的電腦，不會上傳。程式會對外連線的只有：

| 連到哪裡 | 做什麼 | 可以關掉嗎 |
|---|---|---|
| 你設定的監測目標（預設是台灣網路資訊中心、中華電信、Cloudflare、Google 的伺服器）與你的路由器 | 每秒 ping 一次（只是「喊一聲」，不帶任何個人資料） | 在「設定」頁修改目標 |
| `ipinfo.io` | ① 查你的對外 IP 和網路公司名稱（網路環境改變時查一次）② 查「DNS 伺服器是哪家公司的」（只送出 DNS 伺服器的位址；內建名單認得的就不查） | 設定頁取消「查詢對外 IP…」 |
| `speed.cloudflare.com` | 下載測速，**只有你按下按鈕時**才會連 | 不按就不會連 |
| 你輸入的網址 | 路徑分析，**只有你按下按鈕時**才會執行 | 不按就不會執行 |

網頁介面只開放給這台電腦（`127.0.0.1`），同一個 Wi-Fi 的其他裝置連不到。

**資料保存多久**：每秒的原始資料保存 24 小時；每分鐘的平均保存 90 天；定時測試報告會一直保存，直到你自己刪除。想提早刪掉，用各區塊的「清除」或「設定」頁的「清除所有紀錄」（見[下載 CSV 與清除紀錄](#下載-csv-與清除紀錄)）。

## 11. 常見問題

**Q：書籤打開顯示「無法連線」？**
A：背景程式可能沒有正常啟動。請重新雙擊 `安裝.command`；如果還是不行，打開「Finder → 前往 → 前往檔案夾」，輸入 `~/Library/Logs/NetSonar.log`，把內容提供給開發者。

**Q：關掉瀏覽器，背景的程式還在跑嗎？**
A：還在，這是刻意的設計：這樣才能持續記錄，並在網路變差時通知你。想真的停止，到「設定」頁最下方按「⏻ 停止 NetSonar」。

**Q：「應用程式」裡沒有 NetSonar 圖示？**
A：重新雙擊一次 `安裝.command`（圖示是安裝時建立的）。少數電腦沒有權限寫入「應用程式」，這時圖示會放在「家目錄 → 應用程式」資料夾裡。

**Q：安裝時說找不到 Python？**
A：照「[安裝](#2-安裝第一次約-5-分鐘)」的步驟 ① 從 python.org 安裝新版 Python，再雙擊一次 `安裝.command`。

**Q：沒有收到 macOS 通知？**
A：通知是透過系統內建的「工序指令編寫程式」（Script Editor）發出的。請到「系統設定 → 通知」，找到它並允許通知。也要確認「設定」頁有勾選「同時跳出 macOS 通知」。

**Q：開 VPN 之後，所有數字都變差了？**
A：正常。VPN 會把流量先繞到 VPN 伺服器，延遲一定會增加。這時請看「路由器」那張卡片，它才是你家網路的真實狀況。

**Q：有的目標一直顯示「無回應」？**
A：有些網站或 VPN 會擋掉 ping。如果其他目標都正常、只有它一直沒回應，程式會自動暫停對它的警示，你可以到「設定」頁把它刪掉。

**Q：某個目標一直跳警示，但我知道它本來就比較慢？**
A：到「設定」頁，在那個目標的「慢的時候 警示門檻」填一個比較大的數字（例如 250），或勾選「靜音」。

**Q：電腦睡眠時會怎樣？**
A：睡眠期間不會量測，醒來後自動繼續。圖上那段會是空白。

**Q：會不會很耗電、拖慢電腦？**
A：每秒只送幾個很小的封包，負擔非常低。「設定」頁下方的「程式健康度」可以看到程式本身有沒有被拖慢。

## 12. 進階：用終端機啟動

給想看執行過程或修改程式的人。在專案資料夾執行：

```bash
./run_dashboard.sh
```

- 第一次會自動準備好需要的元件（建立 `dashboard/.venv` 虛擬環境並安裝套件）。
- 會自動打開瀏覽器；按 `Ctrl + C` 結束，關掉終端機視窗也會停止。
- 這種方式的資料存在 `dashboard/` 資料夾裡，和背景服務的資料是分開的。
- 如果已經用 `安裝.command` 裝好背景服務，兩者會搶同一個網址，腳本會偵測到並直接幫你打開網頁。

**開發者測試**：
```bash
cd tests
../dashboard/.venv/bin/python -m pip install pytest httpx   # 第一次
../dashboard/.venv/bin/python -m pytest -q
```

架構與技術說明見 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 14. 專案裡有哪些檔案

```text
net-sonar/
├── 安裝.command          ← 雙擊安裝（開機自動在背景執行）
├── 解除安裝.command      ← 雙擊移除
├── run_dashboard.sh      ← 進階：用終端機啟動儀表板
├── net_probe.sh          ← 另一個工具：命令列體檢腳本
├── dashboard/            ← 儀表板的程式
│   ├── web/              ← 網頁畫面（index.html、圖示）
│   ├── config.json       ← 預設設定（在網頁「設定」頁改的內容會另外存，不會改到這裡）
│   └── *.py              ← 各功能的程式，每支檔案開頭都有白話說明
├── scripts/
│   ├── netsonar_service.sh   ← 安裝／移除背景服務的實際步驟（安裝檔會呼叫它）
│   └── git-hooks/            ← 開發用：commit／push 前的自動檢查
├── assets/
│   └── NetSonar.icns     ← 「應用程式」裡那個圖示的圖檔
├── tests/                ← 自動化測試（確認程式算得對；`test_docs.py` 檢查說明文件有沒有跟上程式）
├── docs/
│   ├── ARCHITECTURE.md   ← 儀表板是怎麼組成的
│   ├── NET_PROBE_SH.md   ← 命令列腳本的完整說明
│   └── RESOURCES.md      ← 相關工具與參考資料
├── legacy/               ← 最早的原始腳本（保留對照）
├── CHANGELOG.md          ← 每次更新改了什麼
├── CLAUDE.md             ← 給 AI 助理的協作守則（改程式後要檢查文件、git 設定等）
└── LICENSE               ← 授權條款
```

**想學程式？** 每支 `dashboard/*.py` 開頭都有一段說明它負責什麼、為什麼這樣寫。建議從 `stats.py`（純計算，最好懂）開始，再看 `probe.py`（怎麼 ping）、`advice.py`（怎麼把數字翻成建議）。命令列腳本 `net_probe.sh` 有逐段的初學者註解。
